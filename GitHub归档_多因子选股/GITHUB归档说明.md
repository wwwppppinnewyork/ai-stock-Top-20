# GitHub 归档说明

该目录是多因子选股项目的源码归档版，可作为 GitHub 仓库根目录。

## 已收录

- `src/`：股票池、六因子计算、历史回填、Top5/Top10回测、网页生成和本地服务。
- `config/`：当前股票池规则和六因子权重。
- 根目录脚本：Wind更新、周定时任务、网页启动和权重更新。
- 说明文档：项目使用、因子定义和流程说明。

## 未收录

Wind原始数据、历史因子快照、排名结果、回测输出、公司研究报告、日志、缓存、历史配置备份和个人快捷方式均未收录。这些内容也已写入 `.gitignore`。

## 安全说明

源码不保存 OpenAI API Key，只从用户环境变量 `OPENAI_API_KEY` 读取。Wind 数据需在已安装并登录 Wind 终端的 Windows 电脑上通过 WindPy 访问。上传前不要手工把 `.env`、密钥、Wind导出数据或研究结果复制到该目录。

## 上传建议

1. 在该目录中初始化 Git 仓库。
2. 先检查 `git status` 列出的文件。
3. 确认没有 `data/`、`output/`、`logs/`和 `.env` 后再提交上传。
