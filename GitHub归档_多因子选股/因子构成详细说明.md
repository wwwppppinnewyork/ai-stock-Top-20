# 多因子选股：因子构成详细说明

本文严格依据当前执行代码 `src/wind_data.py`、`src/stock_workflow.py` 与 `config/weights.json` 整理。

## 一、排名前的硬性条件

候选池合并AI赛道股票与A股ETF年内涨幅前50名对应的前十大持仓，去重并剔除ST、*ST和退市标的。进入打分前必须同时满足：（1）最新已披露的Wind合并利润表实际单季度净利润有数据且严格大于0；（2）今年、明年、后年至少有一个Wind分析师预测增长率有效。三年预测全部缺失的公司不予关注，直接剔除排名。

## 二、标准化

除特殊规则外，各子因子在当周通过资格筛选后的候选池内单独进行横截面min-max标准化：

- 正向：`S = (x - min) / (max - min)`，指标越大得分越高。
- 反向：`S = 1 - (x - min) / (max - min)`，用于PEG，指标越小得分越高。
- 单项缺失：除分析师预测变化率外，标准分按0.5中性值处理；PEG反向后缺失仍为0.5。分析师预测变化率缺失时为0分。
- 如果某项全部有效值相同：正向因子的有效值按1、缺失按0.5；反向PEG的有效值按0、缺失按0.5。这是当前代码的实际边界行为。

## 三、六个一级因子

### 1. 分析师预测净利润同比：15分

内部年度权重：今年50%、明年30%、后年20%，对应总分上限7.5、4.5、3分。

- 今年：Wind `WEST_NETPROFIT_YOY`。
- 明年：`(明年一致预期净利润 - 今年一致预期净利润) / |今年一致预期净利润| × 100`。
- 后年：`(后年一致预期净利润 - 明年一致预期净利润) / |明年一致预期净利润| × 100`。
- 三年分别正向标准化，再按5:3:2合成。

公式：`同比小分 = 15 × (今年S×0.50 + 明年S×0.30 + 后年S×0.20)`。

### 2. PEG：20分

内部年度权重：今年50%、明年30%、后年20%，对应总分上限10、6、4分。

- 各年度PE：`总市值 / 该年度Wind一致预期净利润`。
- 各年度PEG：`该年度PE / 该年度预测净利润增长率`。
- 预测净利润必须大于0，增长率必须大于0，否则该年度PEG为空值。
- 三年PEG分别反向标准化，再按5:3:2合成。

公式：`PEG小分 = 20 × (今年反向S×0.50 + 明年反向S×0.30 + 后年反向S×0.20)`。

特别规则：只要明年PEG或后年PEG任意一个小于0，整个PEG一级因子直接记0分；负PEG不参与有效PEG的横截面标准化，其他四个一级因子仍正常计分。

### 3. 实际单季度净利润环比：48分

数据字段为Wind `QFA_NET_PROFIT_IS`，参数 `rptType=1`，表示合并利润表实际单季度净利润，不是累计利润、归母净利润或扣非归母净利润。

- 环比：`(本季度单季度净利润 - 上季度单季度净利润) / |上季度单季度净利润| × 100`。
- 上季度利润为0时，环比为空值并按中性标准分0.5处理。
- 基础环比增长率做正向横截面标准化。
- 最近连续5个季度环比均增长（需要6个连续自然季度数据），直接取得48分。
- 这5个季度不要求全部为正，可以从亏损逐季收窄并转为盈利；但最新季度必须严格大于0才能进入排名。
- 不满足连续5季度增长时：`环比小分 = 基础标准分 × 0.80 × 48`，最高38.4分。

### 4. 最近一期连续增长不中断季度数：1分

从最新一期向前统计实际单季度净利润严格增长的连续次数：最新一期未增长记0，连续1次增长记1，连续4次增长（5个季度逐季增长）记4。原始季度数不做MAD去极值，直接在当期合格候选池内做正向min-max标准化，最高1分。

### 5. 分析师预测变化率：-10至+10分

内部年度权重：今年50%、明年50%，对应总分上限各5分。

对今年和明年分别取当前与2026-07-28两个时点的Wind一致预期净利润增长率：

- `预测变化率 = 当前预测净利润增长率 - 2026-07-28预测净利润增长率`，单位为百分点。
- `|预测变化率| < 0.5个百分点`时强制记0，属于“没有实质变化”。
- 上修和下修分开做有符号标准化：各年度最强上修映射为+1，最强下修映射为-1，其余值按同方向最大绝对值缩放。
- 预测变化率为正就得正分，为负就得负分；变化率为0或没有分析师预测时得0分。
- 今年、明年再按5:5合成，各年对总分的贡献范围为-5至+5分。
- 跨年时代码自动在FY1、FY2、FY3之间切换，追踪同一个具体预测年度。

公式：`变化率小分 = 10 × (今年有符号S×0.50 + 明年有符号S×0.50)`。

### 6. 质量综合：10分

年度权重：上年同期50%、当年同期50%，每年对总分贡献上限为2.5分。

每年内部权重：单季度ROE 34%、单季度毛利率33%、单季度净利率33%。

- Wind `QFA_ROE`。
- Wind `QFA_GROSSPROFITMARGIN`。
- Wind `QFA_NETPROFITMARGIN`。
- 上年与当年同一报告期的三项指标分别做正向标准化。
- 每年先按34:33:33合成，再按上年50%、当年50%合成。
- 任一指标没有数据时，该指标标准分直接记0；不按0.5中性分处理。

公式：`年度质量S = ROE S×0.34 + 毛利率S×0.33 + 净利率S×0.33`。

`质量小分 = 5 × (上年质量S×0.50 + 当年质量S×0.50)`。

当前代码衡量上年与当年同期的单季度ROE、单季度毛利率和单季度净利率水平组合；两年使用相同月日的财务报告期。

## 四、最终总分

`总分 = 预测净利润同比小分 + PEG小分 + 单季度净利润环比小分 + 预测变化率小分 + 质量综合小分`

理论最高分仍为100分，分析师预测变化率因子可因下修贡献负分。每天21:00更新候选池和Wind数据后，重新确定合格股票、重新做横截面标准化并重新排名。

## 五、XGBoost 对照模型（实验）

XGBoost 模型使用与上述规则打分相同的16个原始因子字段，但不使用人为设定的权重和分段规则：每期横截面先做3倍MAD缩尾和排名标准化，再由梯度提升树学习因子与下一期（5个交易日）相对收益排名之间的关系。训练采用滚动扩展窗口并隔离1期，所有评估均为样本外。详细说明见 `README.md` 的“XGBoost 机器学习打分”一节，参数见 `config/xgboost.json`。
