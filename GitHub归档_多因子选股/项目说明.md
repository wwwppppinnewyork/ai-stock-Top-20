# 多因子选股（Wind API版）

## 快速使用

1. 确保Wind金融终端已经登录。
2. 双击 `一键更新.bat`，等待Wind取数、评分和网页生成完成。
3. 双击 `打开看板.bat` 查看最新网页。

## 目录说明

- `查看结果/`：日常直接查看的中文成果文件。
- `src/`：Wind数据接口、候选池、评分和网页生成程序。
- `config/`：因子权重与候选池配置。
- `data/wind/`：Wind原始数据及中间结果。
- `output/`：程序生成的标准结果文件。

## 当前口径

- 候选池：截至数据日的全部A股（沪、深、北交所，不含三板），不设置年度涨幅门槛。
- 剔除：ST、*ST、退市、三板和其他非标准A股。
- 选股周期：每周最后一个交易日收盘后生成六因子信号，下一交易日调仓；收益率曲线按周测算。
- 柱状图：Wind `QFA_DEDUCTEDPROFIT`，每个季度独立的单季度扣非归母净利润，不是累计值。
- 排名：48%利润环比因子使用Wind合并利润表实际单季度净利润；最近连续5个季度环比均严格增长（需要6个连续自然季度数据）时取得满分。另设1%最近一期连续增长不中断季度数因子，不做MAD去极值。最新单季度利润缺失或小于等于0不参与排名。
- 标准化：所有连续型原始因子先按合格候选池横截面做3倍MAD去极值，再执行各自的正向、反向或有符号标准化。
- 审计：534只股票、22,356项Wind数值与派生公式核对，数值不一致0项；上述排名口径与原README存在一项未决冲突。
